# ردکار (Radcar) — WebView / mobile web release

## لینک

- Web: https://mmatin79-beep.github.io/radcar/
- GitHub: https://github.com/mmatin79-beep/radcar

این نسخه از ابتدا برای دوربین موبایل، گزارش تصویری و WebView راست‌چین طراحی شده است.

## آنچه واقعاً کار می‌کند

- انتخاب اطلاعات پایه خودرو بدون اجبار به واردکردن هویت یا پلاک
- ثبت عکس از چهار نما با دوربین یا گالری
- بررسی محلی و تقریبی کیفیت عکس: نور، وضوح ظاهری، بازتاب روشن
- امکان لمس عکس و ثبت/حذف نشانه روی نقطه خاص، همراه ذره‌بین
- نقشه قابل لمس ۶ ناحیه بدنه و یادداشت وضعیت هر ناحیه
- ۳ سؤال فنی کوتاه و قابل رد کردن
- گزارش جمع‌بندی با شاخص پوشش ۱۳ بخشی (نه امتیاز سلامتی)
- کپی/اشتراک متن گزارش، چاپ از مرورگر، ذخیره خلاصه در localStorage

**مهم:** تصاویر تا پایان همین جلسه در حافظه صفحه می‌مانند و به سرور ارسال نمی‌شوند. آرشیو، فقط خلاصه بدون تصویر را نگه می‌دارد. در مرور خصوصی یا هنگام پاک‌کردن داده مرورگر، آرشیو قابل اتکا نیست.

## محدوده تشخیص

این فایل هیچ مدل بینایی یادگیری ماشین یا بک‌اند تشخیص آسیب ندارد. فقط کیفیت عمومی عکس با الگوریتم سبک داخلی بررسی می‌شود. خط‌وخش، فرورفتگی، رنگ‌شدگی، شاسی و وضعیت فنی از عکس به شکل خودکار تعیین نمی‌شوند؛ نشانه‌ها و پاسخ‌ها صرفاً ثبت خود کاربرند. برای تشخیص واقعی به مدل اعتبارسنجی‌شده و یک API امن نیاز است. هرگز کلید API خصوصی را در HTML یا APK قرار ندهید.

## Android WebView

1. فایل `android/MainActivity.kt` را متناسب با پکیج اپ کپی/تلفیق کنید؛ این نمونه مبتنی بر Activity ساده اندروید است و `androidx.core:core` برای FileProvider می‌خواهد.
2. مجوز `INTERNET`، provider و manifest نمونه را در پروژه اصلی ادغام کنید.
3. `android/file_paths.xml` باید در `app/src/main/res/xml/file_paths.xml` قرار بگیرد.
4. کد اپ این URL را بارگذاری می‌کند: `https://mmatin79-beep.github.io/radcar/`.
5. انتخاب فایل در WebView بدون `onShowFileChooser` کار نمی‌کند؛ نمونه آن را همراه با دوربین سیستم پیاده کرده است.
6. برای تولید APK، اپ را با تنظیمات signing خودتان بیلد کنید. این بسته *خود APK* نیست و باید در پروژه Android Studio ادغام و روی گوشی واقعی تست شود.

## حریم خصوصی

- هیچ درخواست آپلود عکس به سرور در کد وجود ندارد.
- عکس‌ها پس از خروج یا بارگذاری مجدد صفحه پاک می‌شوند.
- تاریخ، نام اختیاری خودرو، میزان تکمیل و عناوین موارد مهم فقط پس از فشردن «ذخیره پرونده» در localStorage ذخیره می‌شوند.
- فونت Vazirmatn از Google Fonts در صورت دسترسی بارگذاری می‌شود؛ در حالت آفلاین فونت سیستم به‌کار می‌رود. اگر کاملاً آفلاین می‌خواهید، فونت را در assets پروژه با مجوز مناسب قرار دهید یا همین fallback را نگه دارید.

## محدودیت‌ها

- چاپ در وب با `window.print()` کار می‌کند؛ در Android WebView بهتر است مسیر `radcar://print` را از native WebView مدیریت کنید (در MainActivity نمونه فراهم شده است).
- کیفیت تصویر تخمینی است و بسته به محتوای عکس ممکن است هشدار اشتباه بدهد.
- بارگذاری صفحه آنلاین نیازمند اینترنت است. برای استفاده آفلاین `index.html` را در assets قرار داده و به جای `startUrl` آدرس `file:///android_asset/index.html` را بارگذاری کنید؛ تنظیمات دسترسی فایل و origin را متناسب با مدل امنیتی خود اصلاح کنید.
